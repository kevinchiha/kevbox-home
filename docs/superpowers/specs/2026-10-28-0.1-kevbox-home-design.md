# 0.1-kevbox-home: Couch reshaped into KevBox Home

## Goal

On a KevBox member's Xiaomi TV Box S 3rd gen (and Kevin's TCL test TV), one app Kevin owns,
KevBox Home, replaces both Projectivy and tvQuickActions: Home opens it, KevBox Live, KevBox TV and
SmartTube sit up front with what each has to offer, the other apps wait in a drawer, the remote's
app buttons open Kevin's apps, and the whole setup loads from one file his setup script pushes.

## Scope

- **Identity and fork hygiene:** application id, label, a `kevbox/` package for new code, a hook
  list for upstream merges, a repo `AGENTS.md`.
- **Removals:** Godmode, debloat, the built-in ADB client, Other TVs, the frame HUD and benchmark,
  ambient mode, the Rows layout, the HDMI inputs row and the Inputs pill.
- **Provisioning:** a JSON file pushed over ADB, applied on start, plus a provisioning script and an
  example file matching Kevin's current boxes.
- **Home screen (Index layout):** fixed left column with status lines, More apps, the top-right
  buttons, a full-screen backdrop.
- **Drawer** for every other app.
- **Hold-OK menu:** App info, Move, Restart app, Uninstall.
- **Remote keys and Home takeover** through the existing accessibility service.
- **Updates** from tv.kevbox.dev instead of GitHub.
- **Customize page** trimmed to what is kept.
- **Build:** the four-part version number, English-only resources, the APK size limit.
- **Tests and docs** for the above.

## Acceptance criteria

### Identity and fork hygiene

- **AC-1** The release build installs as `tv.kevbox.home` and shows the label "KevBox Home" on the
  TV, in Android's app list and in Android's accessibility settings. The debug build installs beside
  it as `tv.kevbox.home.dev`. The Kotlin package and `namespace` stay `cloud.samlo.couch`. No string
  in `app/src/main/res/values/strings.xml` contains "Couch".
- **AC-2** All new Kotlin code lives under `app/src/main/java/cloud/samlo/couch/kevbox/`, and its
  tests under `app/src/test/java/cloud/samlo/couch/kevbox/`. `UPSTREAM-SYNC.md` at the repo root
  has one row (path, what changed, why) for every file that exists on `upstream/main` and differs on
  `main`, deleted files included.
- **AC-3** A root `AGENTS.md` says: nothing is pushed, published or installed on a member box until
  Couch carries a licence (samuelloranger/couch#17), and the repo is deleted if the author
  refuses; Couch updates come in by merging `upstream/main`, never by rebasing; how to build, test
  and provision. No `CLAUDE.md` exists anywhere in the repo.
- **AC-4** Godmode, debloat, the built-in ADB client, Other TVs (sync), the frame HUD and benchmark,
  and ambient mode are gone: the source packages `godmode`, `debloat`, `adb`, `sync` and `measure`,
  the files `home/AmbientMode.kt`, `ui/Ambient.kt` and `ui/GodBadge.kt`, and `assets/debloat/` no
  longer exist; the manifest has no `.godmode.SleepReceiver`; a search of `app/src` for
  `couch.godmode`, `couch.debloat`, `couch.adb`, `couch.sync` and `couch.measure` finds nothing; and
  no screen, key sequence or setting leads to them.
- **AC-5** Index is the only layout. No setting offers Rows, and a `config.json` holding
  `"layout": "rows"` loads with `layout` = `index`. The HDMI inputs row, the Inputs pill and the
  Inputs settings page never appear.

### Provisioning

- **AC-6** When Home starts or resumes and
  `/sdcard/Android/data/tv.kevbox.home/files/kevbox-home.json` exists (`tv.kevbox.home.dev` for the
  debug build), KevBox Home applies it to `config.json` and renames it `kevbox-home.applied.json`,
  replacing any earlier one. A file that is not a JSON object is renamed
  `kevbox-home.rejected.json`, `config.json` keeps its content, and the reason is logged under the
  tag `KevBoxHome`.
- **AC-7** The provision file accepts these keys, documented with a full example in
  `docs/kevbox/provisioning.md`: `apps` (left column, ordered package list), `drawer` (packages
  shown first in the drawer, in order), `hidden` (packages never shown in the left column or the
  drawer, even when also listed in `apps`), `buttons` (top-right, ordered, from `wifi`, `vpn`,
  `bluetooth`, `speedtest`, `settings`; other values are dropped), `speedtestApp` (a package),
  `keys` (remote map, AC-27) and `wallpaper` (`daily`, `reddit`, `gradient` or `custom`, where
  `custom` shows `wallpaper.jpg` from the same folder). A key present in the file replaces the
  saved value. Unknown keys are ignored; a missing key, or a key whose value has the wrong type,
  keeps the current value.
- **AC-8** `kevbox/provision/provision.sh <file>` exits non-zero before touching the device unless
  `adb devices` lists exactly one device in state `device`, or `ANDROID_SERIAL` names one that is.
  It then, in order: pushes the file to the AC-6 path; runs `pm grant` for `READ_TV_LISTINGS`,
  `WRITE_SECURE_SETTINGS`, and `BLUETOOTH_CONNECT` when the device's SDK is 31 or higher; runs
  `appops set tv.kevbox.home GET_USAGE_STATS allow`; adds
  `tv.kevbox.home/cloud.samlo.couch.HomeAccessibilityService` to `enabled_accessibility_services`,
  keeping every service already listed, and sets `accessibility_enabled` to 1; runs
  `cmd package set-home-activity tv.kevbox.home/cloud.samlo.couch.MainActivity`; starts the app;
  sends `KEYCODE_HOME`; and checks that `dumpsys activity activities` shows
  `tv.kevbox.home/cloud.samlo.couch.MainActivity` as the resumed activity. Any failed step prints
  one red line naming it and exits non-zero.
- **AC-9** `kevbox/provision/kevbox-home.example.json` describes Kevin's current boxes: `apps` =
  `tv.kevbox.live` (KevBox Live), `tv.kevbox` (KevBox TV), `org.smarttube.stable` (SmartTube);
  `drawer` = `com.surfshark.vpnclient.android` (Surfshark), `com.rma.netpulsetv` (Speedtest),
  `com.android.vending` (Play Store), `nextapp.fx` (FX), `com.esaba.downloader` (Downloader),
  `org.videolan.vlc` (VLC); `keys` = the AC-28 map.

### Home screen

- **AC-10** The left column shows exactly the `apps` packages that are installed and have a TV
  launcher entry, in the saved order, minus `hidden`. Usage never reorders it. With no `apps`
  saved, or none of them installed, the column holds only "More apps" (AC-12).
- **AC-11** Each app row shows the app's icon, its name and one status line under the name,
  ellipsised to one line, and nothing else (no screen-time figure). When the first card of the
  app's channel row (AC-13) has a saved playback position and a duration, both above zero, the
  line is "<title> · <episode> · <time left>": the episode as "S2 E4", or "E4" without a season,
  left out when unknown; the time left as "31 min left", or "1 h 05 left" from an hour up.
  Otherwise the line is "Opened " plus Couch's last-opened text ("Opened today at 10:20", "Opened
  yesterday at 22:37", "Opened Wednesday at 22:37", following the 24-hour clock setting). With no
  usage in the last seven days either, the row has no status line. Example: a KevBox TV Continue
  watching card at S2 E4 with 31 minutes to go reads "Severance · S2 E4 · 31 min left";
  SmartTube's recommendations carry no position, so SmartTube reads "Opened …".
- **AC-12** Under the app rows, past a divider, a "More apps" row is always present. Down from the
  last app row reaches it, and OK on it opens the drawer.
- **AC-13** The right side for the selected app keeps Couch's Index content: the spotlight text,
  the app's channel row and the week's screen-time chart. Behind the whole screen, a backdrop shows
  the focused program's art (the first card's when focus is in the left column), and the wallpaper
  when there is none; Customize's Dim setting (light, medium, strong) darkens it.
- **AC-14** The top right shows the `buttons` in order, then the clock and the weather. With no
  `buttons` saved, the order is wifi, vpn, bluetooth, speedtest, settings. While an update waits
  (AC-31), Couch's Update chip shows left of the buttons.
- **AC-15** The Wi-Fi button's icon shows Wi-Fi with a signal level from 0 to 4, Ethernet, or no
  network, plus a green dot while the active network has validated internet
  (`NET_CAPABILITY_VALIDATED`). OK opens Android's network settings.
- **AC-16** The VPN indicator appears only while a network with `TRANSPORT_VPN` is active,
  whichever app made it, and disappears within 2 s of the VPN dropping. It shows a shield icon and
  the word "VPN", takes no focus, and Left and Right along the buttons skip it.
- **AC-17** The Bluetooth button's icon shows off, on, or on with the number of connected devices.
  OK opens Android's Bluetooth settings. The manifest declares `BLUETOOTH_CONNECT`, and `BLUETOOTH`
  with `maxSdkVersion` 30.
- **AC-18** The Speed test button opens `speedtestApp` (default `com.rma.netpulsetv`) and is left
  out when that app is not installed.
- **AC-19** The Settings button always shows a cog and the word "Settings". OK opens Android's
  settings; holding OK opens KevBox Home's Customize page.
- **AC-20** The Wi-Fi, Bluetooth and Speed test buttons show only their icon until focused, then
  widen to their text: "Wi-Fi · strong" (level 3–4), "Wi-Fi · fair" (2), "Wi-Fi · weak" (0–1),
  "Ethernet", "No network"; "Bluetooth · off", "Bluetooth · on", "Bluetooth · 2 connected";
  "Speed test". Up from the left column's first row, and Up from any card in the channel row, move
  focus to the first focusable button. Down from the buttons returns focus to the row or card it
  came from.

### Drawer

- **AC-21** The drawer is a full-screen grid, 5 columns at 1920×1080, of every app with a TV
  launcher entry (`LEANBACK_LAUNCHER`) other than KevBox Home that is neither in `apps` nor in
  `hidden`: `drawer` packages first in their order, the rest alphabetical by label. OK opens the
  focused app. Back closes the drawer and returns focus to "More apps".
- **AC-22** The remote's ALL_APPS key, and any key mapped to the `drawer` action, opens the drawer
  from Home or from any app.

### Hold-OK menu

- **AC-23** Holding OK on an app in the left column or in the drawer opens a menu with App info,
  Move, Restart app and Uninstall, in that order, and nothing else. Uninstall appears only where
  AC-37 allows it, so never in the left column.
- **AC-24** App info opens Android's app details page for that package
  (`ACTION_APPLICATION_DETAILS_SETTINGS`).
- **AC-25** Move lets the arrows shift the app within its own list: Up and Down in the left column;
  Left and Right by one place and Up and Down by one row in the drawer. OK or Back places it. The
  new order is saved in `config.json` (the drawer's whole order becomes its saved `drawer` list)
  and survives a reboot. A later provision file with `apps` or `drawer` replaces it.
- **AC-26** Restart app has the accessibility service open the app's details page, press the TV
  settings app's Force stop control and its confirmation, then relaunch the app. The service finds
  the control by the settings app's own string resource, so it works with the TV's system language
  set to English and to French. When Force stop is greyed out (the app is not running), it skips to
  the relaunch. If a step has not succeeded within 5 s, or the accessibility service is off, the
  run stops on the details page and shows the toast "Press Force stop, then reopen the app".

### Remote keys and Home

- **AC-27** `res/xml/home_accessibility.xml` declares `android:canRequestFilterKeyEvents="true"`
  and the `flagRequestFilterKeyEvents` flag, and the service filters key events. `keys` is an array
  of entries such as `{"keycode": 193, "scancode": 416, "package": "tv.kevbox"}` or
  `{"keycode": 284, "scancode": 216, "action": "drawer"}`. An entry needs a keycode, a scancode or
  both, and exactly one of `package` or `action` (`home` or `drawer`); any other entry is ignored.
  A key event matches an entry when its keycode or its scancode equals the entry's. For a matched
  key the service consumes the key-down, its repeats and the key-up, and acts once, on key-up.
  Keys with no matching entry pass through untouched, so holding volume still ramps.
- **AC-28** The default map, used until a provision file sets `keys`: Netflix (keycode 193 /
  scancode 416) opens `tv.kevbox`; Prime Video (194 / 207) opens `tv.kevbox.live`; YouTube (190 /
  425) opens `org.smarttube.stable`; Home (3 / 172) runs `home`, which shows KevBox Home; ALL_APPS
  (284 / 216) runs `drawer`.
- **AC-29** A mapped key opens its target within 500 ms of key-up, from any app, while Google's
  launcher is still installed. When the target package is not installed, the key passes through.
- **AC-30** With key filtering on, Home from any app shows KevBox Home and the stock launcher never
  comes to the front. Couch's window-state takeover (`HomeAccessibilityService.isStockHome`) stays:
  when the stock launcher's home window appears anyway, KevBox Home opens over it.

### Updates

- **AC-31** The daily update check, while Check for updates is on, reads
  `https://tv.kevbox.dev/home/version.json` (`versionCode`, `versionName`, `url`, `sha256`,
  `notes`, the shape KevBox TV uses; `sha256` is the APK's hex hash). The Update chip offers
  "Update <versionName>" only when `versionCode` is higher than the installed one and `url` is
  `https://` on host `tv.kevbox.dev`. The APK is installed only when its SHA-256 matches `sha256`,
  case-insensitively; a mismatch shows Couch's checksum error and installs nothing. No source file
  or string mentions `api.github.com` or GitHub.
- **AC-32** `update/Installer` still performs the download, the SHA-256 check and the install
  through Android's package installer, and the top bar's Update chip and Customize's About row
  start it, as in Couch.

### Kept features and settings

- **AC-33** Weather, wallpapers and the screen-time chart work as in Couch. The Customize page
  offers exactly: the four permission rows (HOME button, notification access, usage access, TV
  listings), accent colour, wallpaper source, subreddit, image interval, dim, app channels, 24-hour
  clock, weather on or off, °C or °F, Check for updates and About. It has no Layout, Card size,
  Names under cards, Descriptions, Date, Rows, Inputs, Show or hide apps, Rearrange apps, City,
  Ambient mode, Other TVs, Android settings, Godmode or pre-release entry.

### Quality

- **AC-34** `./gradlew testReleaseUnitTest lintRelease assembleRelease` passes with zero lint
  errors. JVM unit tests cover provision parsing and merging (AC-6, AC-7), the key map (AC-27,
  AC-28), the status-line text (AC-11), `version.json` parsing (AC-31) and the button state text
  (AC-20).
- **AC-35** `app/build/outputs/apk/release/app-release.apk` is at most 1,048,576 bytes.
- **AC-36** `docs/kevbox/test-on-tv.md` is a checklist Kevin runs on the TCL test TV (Projectivy's
  accessibility service switched off first) and on a Xiaomi box. It covers at least AC-1, AC-6,
  AC-8, AC-9, AC-10 to AC-30, AC-33, AC-37 and AC-38, each with the exact key presses and what
  should appear.

### Hold-OK menu: Uninstall

- **AC-37** Uninstall opens Android's own uninstall confirmation for that package (the manifest
  declares `REQUEST_DELETE_PACKAGES`); nothing is removed without that confirmation. It is offered
  only for apps installed by the user (`FLAG_SYSTEM` unset) or updated over a system app
  (`FLAG_UPDATED_SYSTEM_APP` set), never for a system app with no updates, and never for the
  packages in `apps`. Once the package is gone, it leaves the left column or the drawer within 2 s,
  while Home stays open, with no restart.

### Build

- **AC-38** The app shows English whatever the TV's system language: the build keeps English
  resources only (Gradle `androidResources.localeFilters`), and Couch's `values-fr` folder stays in
  the source untouched.
- **AC-39** The version is Couch's version plus a fourth number: `0.8.1.1`, `0.8.1.2`, then
  `0.9.0.1` after merging Couch 0.9.0. Release tags are `vX.Y.Z.N`; the build takes the highest
  version among all `v*` tags reachable from HEAD (Couch's three-part tags count as `.0`), not the
  nearest tag. `versionCode` = X·1,000,000 + Y·10,000 + Z·100 + N, so `0.8.1.0` is 80,100,
  `0.8.1.1` is 80,101 and `0.9.0.1` is 90,001: it rises with every release and with every Couch
  version merged in.

## Non-goals

- **KevBox Live's "Recent channels" row.** It needs a change in KevBox Live itself (the OwnTV
  repo); it is the next phase. Until then KevBox Live's status line is "Opened …".
- **"Restart yourself" hooks inside KevBox TV and KevBox Live.** The accessibility route covers
  every app; app-side hooks can come later.
- **The release key, the first signed release, the upload to tv.kevbox.dev, and switching
  `~/Scripts/combined.sh` to KevBox Home.** Kevin does these by hand once the licence lands.
- **Installing on any member box** before Couch has a licence.
- **Switching Wi-Fi, Bluetooth or the VPN on and off from the launcher.** Android does not let an
  ordinary app do it; the buttons show state and open the right screen.
- **A quick-settings panel.** Kevin picked the row of buttons.
- **Hide, Rename and Change icon in the hold-OK menu.** Members should not be able to rearrange
  what Kevin set; the provision file decides what is visible.
- **Long-press and double-press remote mappings.** tvQuickActions used single presses only.
- **HDMI inputs.** The Xiaomi box has none.
- **French, Arabic or any language but English.** Kevin's call for 0.1; Arabic would also need a
  right-to-left layout.
- **A VPN switch or a link to a VPN app.** The VPN item is an indicator only.
- **Choosing the weather city per box.** Weather stays automatic.
- **Renaming the Kotlin package.** It would make every upstream merge conflict.
- **A visual check by the pipeline.** Kevin checks the screens on a real TV (AC-36).

## Decisions

- Build on Couch (samuelloranger/couch), not Luncher, Vibe Launcher or a blank project: it already
  has the Index layout Kevin picked, a light View-based renderer and most of the plumbing. Couch
  has no licence; Kevin asked for one in samuelloranger/couch#17 and chose to build meanwhile and
  delete the repo if refused.
- Approach B, an upstream-friendly fork, over editing Couch in place (later Couch fixes would
  tangle with ours) and over a swap-first phase (nothing ships before the licence, so an early
  swap buys little).
- Layout A, Couch's Index, over a Google TV-style stage and a three-panel dashboard: Kevin's pick
  from the mockups.
- A row of top-right buttons with Settings always labelled, over a status pill opening a quick
  panel: Kevin's pick; one press per action.
- Keep weather, wallpapers and the screen-time chart; drop Godmode, Other TVs, the HDMI row, the
  Rows layout and ambient mode: Kevin's pick. Godmode's built-in ADB client was also the riskiest
  code to leave on member boxes.
- The hold-OK menu is App info, Move, Restart app and Uninstall, over also offering the app's own
  settings or Hide: Kevin's pick. Uninstall goes through Android's confirmation rather than a silent
  removal, so one stray press cannot delete an app.
- KevBox Home replaces tvQuickActions as well as Projectivy: one accessibility service instead of
  two, and the button map lives in the same provision file.
- The left column follows the provision file's order, over Couch's usage-based sorting: Kevin's
  three apps must not swap places.
- Provisioning through a file in the app's external files folder, over driving the UI or a
  broadcast: `adb push` can write there and nothing on screen has to be tapped.
- KevBox Home installs as `tv.kevbox.home` and keeps the `cloud.samlo.couch` namespace, as KevBox
  TV kept `com.nuvio.tv`: merges stay clean.
- Updates come from tv.kevbox.dev with the KevBox TV `version.json` shape, over Couch's GitHub
  releases: Kevin already runs that server.
- Customize stays open to every member through holding OK on Settings, over switching it off per
  box or adding a PIN: Kevin's call (grill round 1).
- The VPN item is an indicator that appears whenever any VPN is connected, over a Surfshark
  button: Kevin wants a status signal, not a shortcut tied to one VPN app (grill round 1).
- Weather finds its place automatically from the internet address, over a city per box: Kevin's
  call, accepting that a VPN can show another city's weather (grill round 1).
- Uninstall is never offered on the left-column apps, over offering it everywhere: members cannot
  delete KevBox Live, KevBox TV or SmartTube by accident (grill round 1).
- A provision file with `apps` or `drawer` replaces a member's own Move order, over keeping it:
  pushing a file is deliberate, and it puts the box back to Kevin's layout (grill round 1).
- Restart app taps Force stop on screen, so the settings page flashes for about a second, over
  offering no restart: Kevin accepts the flash (grill round 1).
- English only in 0.1, over English and French or adding Arabic: Kevin's call (grill round 1).
- Versions follow Couch's number plus a fourth part (`0.8.1.1`), over a separate numbering of our
  own: Kevin's call (grill round 2), the same habit as KevBox Live's `5.1.0.16`.
- The status line shows a show only when it has a saved watch position, over always showing the
  first program of the first row: SmartTube's first row is recommendations, which mean nothing in a
  status line (grill round 2).
- auto-resolved: Index gets a full-screen backdrop (program art, else the wallpaper, darkened by
  Dim), over keeping Couch's flat Index background, because AC-13 and the approved mockup show one,
  and Couch's Index has none: its wallpaper only showed in ambient mode, which goes.
- auto-resolved: the status line reuses Couch's strings ("S2 E4", "31 min left", "1 h 05 left",
  "today at 10:20"), over new wording, because they exist and match the mockup.
- auto-resolved: the button texts are strong (level 3–4), fair (2), weak (0–1), "No network",
  "off", "on" and "N connected", over leaving them open, because AC-34 tests that text and needs
  fixed values.
- auto-resolved: Up from a channel-row card reaches the buttons, over "Right from the top of the
  right side", because nothing focusable sits above the channel row and Right inside it already
  moves between cards.
- auto-resolved: a `keys` entry matches on keycode or scancode, over requiring both, because a
  remote can report a button with an unknown keycode and a known scancode, and the default map has
  to work on both the TCL and the Xiaomi remote.
- auto-resolved: a provision key with a value of the wrong type is skipped like a missing key, over
  rejecting the whole file, because Couch's `ConfigJson` treats broken values the same way and one
  bad value should not undo the rest of a push.
- auto-resolved: the provision `wallpaper` key takes `config.json`'s four source values, over an
  image path or URL, because Couch's wallpaper code already handles those sources.
- auto-resolved: with no `apps` saved, the left column holds only More apps, over Kevin's three
  apps as a built-in default, because the provision script always sets `apps` and a default would
  guess for a box Kevin has not set up.
- auto-resolved: the example file names the drawer apps by their public package ids, over app names
  alone, because AC-9 must be checkable; the AC-36 checklist confirms them on the test TV.
- auto-resolved: the script grants `BLUETOOTH_CONNECT` only on SDK 31 and up and sets Home with
  `cmd package set-home-activity`, over always granting and using `cmd role`, because the
  permission does not exist below SDK 31 and `set-home-activity` works from SDK 28, the minSdk.
- auto-resolved: Customize keeps Check for updates and About and drops Card size and City, over the
  list as first written, because About shows the installed version and starts an update (AC-32),
  card size changes nothing in Index (Couch hides it there), and a City field would contradict the
  automatic-weather decision.
- auto-resolved: AC-4 is checked on the source tree, over `dexdump` on the release APK, because R8
  renames classes in the release build, so an APK class listing proves nothing.
- auto-resolved: Restart app skips to the relaunch when Force stop is greyed out, and shows the toast
  when the accessibility service is off, over failing in both cases, because both happen on a
  member box.
- auto-resolved: user-visible strings say "KevBox Home" instead of "Couch", accessibility label
  included, over changing `app_name` alone, because members see the other strings (toasts, help
  text, the accessibility list) too.
- Size: 39 criteria, within the cap
- Grill: run to an empty frontier

## Open questions

## UI

- **Look:** Couch's own design system: `ui/Tokens` and `index/IndexTokens` for every colour, size
  and timing, the Hanken Grotesk font, Couch's card, focus ring and motion. The reference for the
  new parts (left column with status lines, More apps, the top-right buttons, the backdrop) is
  `docs/superpowers/specs/assets/0.1-kevbox-home-home.jpg`, the mockup Kevin approved.
- **21st:** no.
- **Platform:** Android TV, plain framework Views (no AndroidX, no Compose), minSdk 28.
- **Charts:** none new; the existing `StatsBar` view stays.
