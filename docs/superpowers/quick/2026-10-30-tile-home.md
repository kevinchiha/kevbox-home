# Tile home

## Goal
Home has no left app list any more: the apps sit as big icon tiles along the bottom, and the
selected app's name, focused card text and two rows of cards fill the screen above them.

## Scope
The Index home screen (`app/src/main/java/cloud/samlo/couch/index/`), `kevbox/home/`, strings,
`UPSTREAM-SYNC.md` and `docs/kevbox/test-on-tv.md`.

**Gate:** `./gradlew --no-daemon testReleaseUnitTest lintRelease assembleRelease && test $(stat -c %s app/build/outputs/apk/release/app-release.apk) -le 1048576`

## Acceptance criteria
- **AC-1** Home shows no list of app names on the left. The apps of `config.apps` that are
  installed and not hidden sit as tiles along the bottom, in that order, icon only (the app's
  name is the tile's content description), then a More apps tile.
- **AC-2** On the first load and on every Home press, focus lands on the first app tile
  (KevBox Live with the example setup file); with no app tiles, on More apps.
- **AC-3** Each app shows at most two rows of cards, picked from the preview channels it
  publishes: `tv.kevbox.live` the row whose name contains "recent" (or "récent") then "favori";
  `tv.kevbox` "continue" then "library" (or "bibliothèque"); SmartTube
  (`org.smarttube.stable`, `org.smarttube.beta`, `com.teamsmart.videomanager.tv`,
  `com.liskovsoft.smarttubetv.beta`) "recommend" then "history". Matching ignores case. A slot
  with no match, and every slot for any other app, takes the app's next unused channel in the
  order `Programs.channels` returns, so KevBox TV today shows Continue Watching alone.
- **AC-4** Each row has a small label above its cards: the channel's name as published.
- **AC-5** The text block on the left shows the app's name alone on its small accent line (no
  ", Continue Watching" after it), then the title, description and progress of the focused card,
  or of the first card of the first row while a tile is focused.
- **AC-6** Left and Right along the tiles swap the text block and both rows to that app. Cards
  of two apps never show together; a row that is still waiting to fill shows empty.
- **AC-7** Up from an app tile goes to the first card of its lowest row; Up from the lower row
  to the upper row; Up from the upper row to the first top button. Down walks back: upper row
  to lower row, lower row to the selected tile, top button to the view Up left from (the
  selected tile when that view is gone).
- **AC-8** Back from any card or top button puts focus on the selected tile.
- **AC-9** An app with no rows shows its name alone in the text block and no rows; Up from its
  tile goes to the first top button.
- **AC-10** Focusing More apps shows the wallpaper behind the screen, "More apps" as the title
  and no rows; OK opens the drawer; Back from the drawer lands on More apps.
- **AC-11** Holding OK on an app tile opens the same menu as before. Its Move shifts the tile
  with Left and Right, OK or Back places it, and the order is saved to `config.apps`. The move
  hint says Left and Right; the drawer's own Move hint is unchanged.
- **AC-12** The week's screen-time chart and the per-app status lines are gone, and Home no
  longer reads usage stats.
- **AC-13** OK on an app tile opens the app; OK on a card opens that program, as before.
- **AC-14** The gate passes, and the release APK is at most 1048576 bytes.
- **AC-15** `docs/kevbox/test-on-tv.md` checks the new layout instead of the left column, and
  `UPSTREAM-SYNC.md` has a current row for every Couch file changed or deleted.

## Non-goals
- No change to KevBox TV, KevBox Live or SmartTube. KevBox TV's Library row comes from a
  separate change in the NuvioTV repo; until it ships, KevBox TV shows one row.
- No setting or setup-file key to choose rows: the three apps are fixed by the setup file, and
  the picks are a table in code.
- No new look: colours, card style, top bar, backdrop and the status line along the bottom stay.
- The 0.1 design spec (`docs/superpowers/specs/2026-10-28-0.1-kevbox-home-design.md`) is not
  edited; this plan supersedes its AC-10 to AC-13 and the column part of AC-25.

## Decisions
- Rows are picked by name keywords over exact names, because the names differ by language
  (KevBox Live ships French) and SmartTube's exact names are not fixed.
- Rewrite `IndexScreen` in place over a new screen class in `kevbox/`, because the fork already
  owns most of that file and a second screen would leave Couch's dead copy to merge forever.
  `AppList`, `AppRow` and `StatsBar` are deleted, with Deleted rows in `UPSTREAM-SYNC.md`.
- Every task that edits a Couch file updates that file's `UPSTREAM-SYNC.md` row in the same
  commit, as `AGENTS.md` requires.
- Tiles show the app's launcher icon, not its TV banner, because the ask was "just big icon".
- Starting layout on the 960×540 dp canvas (the builder may tune): text block x 24, y 96, width
  330; the two rows from x 380, labels at y 70 and 200, cards 99 dp tall under each; tiles
  centred along y 380 to 460, about 120 × 80 dp with a 56 dp icon; the status line stays at the
  bottom.
- Cards still build a couple per frame and fill once the selection rests, as today, because the
  Xiaomi box is weak.

### Task 1: Two rows per app in the data
**Delivers:** AC-3, AC-4 (data side)
**Files:** `app/src/main/java/cloud/samlo/couch/kevbox/home/HomeRows.kt` (new),
`app/src/main/java/cloud/samlo/couch/index/IndexData.kt`,
`app/src/main/java/cloud/samlo/couch/index/IndexScreen.kt` (one call only),
`app/src/test/java/cloud/samlo/couch/kevbox/HomeRowsTest.kt` (new), `UPSTREAM-SYNC.md` (the
`IndexData` and `IndexScreen` rows)
**Interfaces:**
- `class Shelf(val title: String, val tiles: List<Tile>)` in `kevbox.home`; `title` is the
  channel's published name.
- `object HomeRows { fun pick(packageName: String, channels: List<Programs.Channel>): List<Programs.Channel> }`
  returns at most two of the app's channels, in slot order, per AC-3.
- `IndexEntry` gains `val shelves: List<Shelf>` and loses `channelTitle`; `programs` stays as a
  getter for the first shelf's tiles (empty when none). The signature covers every shelf.
**Does:**
- `IndexBuilder` builds each entry's shelves from `HomeRows.pick` over that package's channels.
- The one `channelTitle` use in `IndexScreen` passes the app's label instead (AC-5's accent line).
**Tests:**
- SmartTube with Subscriptions, Recommended, History and Liked picks Recommended then History.
- KevBox Live with French names picks "Chaînes récentes" then "Favoris"; KevBox TV with only
  Continue Watching gets that one row.
- An unknown app with three channels gets its first two.
**Verify:** `./gradlew --no-daemon :app:testDebugUnitTest --tests 'cloud.samlo.couch.kevbox.HomeRowsTest' && ./gradlew --no-daemon :app:compileReleaseKotlin`

**Interfaces:**

- `class AppTiles(context, makeTile: (IndexEntry) -> AppTile) : FrameLayout` with
  `val moreApps: View` (focusable, clickable, never long-clickable, "More apps" as content
  description), `fun tiles(): List<AppTile>`,
  `fun bind(entries: List<IndexEntry>, rebuildAll: Boolean, moveFocus: (AppTile) -> Unit)`
  (reuses tiles by app key and rebinds only changed ones, like `AppList.bind`), and
  `fun select(tile: AppTile?)` (`null` chooses More apps).
**Does:**
- A centred horizontal row of tiles, the More apps tile last with a grid mark.
- The chosen or focused tile is outlined and slightly larger; no layout pass on a focus move
  (scale and outline only).
- `IndexData`'s icon is rendered at the tile's icon size from `IndexTokens`.
**Tests:** none (a view; Task 3 wires it).
**Verify:** `./gradlew --no-daemon :app:compileReleaseKotlin`

  and `HomeScreen` (if touched) say what changed now; `AppList` and `AppRow` move to the Deleted
