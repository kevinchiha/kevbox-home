# Couch 0.9.0 and GPL v3

## Goal
KevBox Home is on Couch 0.9.0 under Couch's GPL v3 licence, says so in the app and the repo, and
its tree is ready to be made public (no secrets or home-network identifiers in tracked files).

## Scope
A merge of `upstream/main` (Couch d3dd5ea, 8 commits: Customize redesign #19-#22, #24, Rows
layout removed #23, remote relay #18, GPL v3 #25), UPSTREAM-SYNC.md, settings/MainPage.kt (About),
strings.xml, README.md, AGENTS.md, docs under docs/kevbox/ and docs/superpowers/.

**Gate:** `export ANDROID_HOME=$HOME/Android/Sdk && ./gradlew --no-daemon testReleaseUnitTest lintRelease assembleRelease && test $(stat -c %s app/build/outputs/apk/release/app-release.apk) -le 1048576 && bash kevbox/provision/provision-test.sh && python3 -m unittest discover -s kevbox/release -p 'test_*.py'`

## Acceptance criteria
- **AC-1** `main` contains `upstream/main` (d3dd5ea) through a merge commit (no rebase, no force
  push), and Couch's `LICENSE` (GPL v3 text) is at the repo root unchanged.
- **AC-2** Every KevBox feature listed in UPSTREAM-SYNC.md before the merge still works in code:
  the left column and its order, the top buttons, the drawer, hold-OK menus with Restart app,
  remote key mapping, Home takeover, provisioning, the updater with silent install, every app
  channel shown by default, Right to the Wi-Fi pill, the clock top left.
- **AC-3** Upstream's new Customize layout (groups rail, row kinds) is taken; KevBox's own rows
  (App channels, About with "check now", accent colour, and what the Settings button's held OK
  opens) sit in it and do what they did before.
- **AC-4** Files KevBox deleted stay deleted (Godmode, debloat, measure/benchmark, adb, ambient,
  Other TVs, Inputs page). Upstream's whole remote relay (#18) is left out: `remote/`,
  `settings/RemotePage.kt`, `bravia/`, `app/src/main/native/relay.c` and the relay build and
  `ndkVersion` in `app/build.gradle.kts`, `RemoteButtonsTest.kt`, `res/xml/network_security_config.xml`
  and its manifest attribute (if only the relay/Bravia use it), the `qs_*` drawables,
  `docs/remote-buttons.md`, and every route to them (e.g. `settings/Groups.kt`). Each gets its own
  row under UPSTREAM-SYNC.md's Deleted section saying why.
- **AC-5** UPSTREAM-SYNC.md has an accurate row for every upstream file the merge left changed or
  deleted, and its header records the merged upstream commit.
- **AC-6** Settings › About shows "KevBox Home is a modified version of Couch by Samuel Loranger,
  licensed under the GNU GPL v3, with no warranty. Source: https://github.com/kevinchiha/kevbox-home"
  (same meaning; exact text in strings.xml), next to the installed version.
- **AC-7** The repo states the licence: README.md keeps Couch's text but gains a short top section
  saying KevBox Home is a modified Couch under GPL v3 and where the changes are listed; AGENTS.md
  gains a "Licence" section with the GPL v3 duties (source for every released APK, keep notices,
  mark changes); docs/kevbox/releasing.md's "Couch still has no licence" note says GPL v3 instead.
- **AC-8** No tracked file contains Kevin's home-network addresses (the `192.168.68` subnet), a Wi-Fi name,
  an email address outside git metadata, a token, password or keystore; the box addresses become
  `<xiaomi box ip>` / `<tcl tv ip>` placeholders. Couch's own example addresses (`192.168.1.x`) stay.
  (History is not rewritten.)
- **AC-9** The Gate passes, and the next release version is documented as `0.9.0.1`.

## Non-goals
- Making the GitHub repo public: Kevin's step after this lands (it publishes).
- Upstream's remote relay (#18): it needs ADB left on inside every box; a separate decision.
- Rewriting git history: the old commits hold only home-LAN addresses; a rewrite needs a force push.
- A new release: Kevin runs release.sh 0.9.0.1 when he wants it.

## Decisions
- Merge, never rebase, as AGENTS.md says.
- Take upstream's Customize redesign and fit KevBox rows into it, over keeping KevBox's old
  settings layout, so later Couch merges stay small.
- Leave out the remote relay (#18) over porting it, because it needs Couch's ADB client, which
  KevBox removed, and an always-on ADB port on member boxes.
- Remote Input and Settings buttons keep Android's behaviour (the relay is out).
