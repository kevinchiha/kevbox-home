# Upstream sync

Merged upstream: Couch 0.9.0, commit `d3dd5ea` ("docs: license Couch under GPL v3 (#25)"), merged
on 2026-10-29. The fork point was `76be0dc` (Couch v0.8.1).

This table lists every file that exists in Couch at the merged commit and differs here, as printed
by `git diff --name-only --no-renames --diff-filter=MD "$(git merge-base upstream/main HEAD)"`,
with what this fork changed in it and why (AC ids are from
`docs/superpowers/specs/2026-10-28-0.1-kevbox-home-design.md` unless a row names another file).
Files only this fork has get no row: the `kevbox/` source, test and script folders, the `ic_kb_*`
drawables in `app/src/main/res/drawable/`, `docs/kevbox/`, `docs/superpowers/`, `release.sh`,
`AGENTS.md` and this file.
